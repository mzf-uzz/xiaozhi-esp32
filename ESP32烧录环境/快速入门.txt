============================================
ESP32 烧录环境快速入门指南
============================================

欢迎使用小智桌面机器人烧录环境！

📋 快速开始步骤：

============================================
方式一：Windows 命令提示符 (推荐)
============================================

0️⃣ 安装 ESP-IDF (一键配置)
   双击运行: setup_full.bat
   - 自动使用代理下载 ESP-IDF v5.5
   - 自动安装到 F:\esp-idf
   - 自动配置环境变量
   - 预计耗时: 30-60 分钟

1️⃣ 测试环境
   双击运行: test_env.bat
   确保所有测试项显示 [通过]

2️⃣ 启动环境
   双击运行: start_idf.bat
   等待 ESP-IDF 环境加载完成

3️⃣ 烧录固件
   双击运行: flash.bat
   选择烧录模式并输入串口端口

============================================
方式二：Git Bash (推荐用于开发)
============================================

0️⃣ 安装 ESP-IDF (一键配置)
   在 Git Bash 中运行:
   chmod +x setup_full.sh
   ./setup_full.sh
   - 自动使用代理下载 ESP-IDF v5.5
   - 自动安装到 F:\esp-idf
   - 自动配置环境变量
   - 预计耗时: 30-60 分钟

1️⃣ 测试环境
   chmod +x test_env.sh
   ./test_env.sh

2️⃣ 启动环境
   chmod +x start_idf.sh
   source ./start_idf.sh

3️⃣ 烧录固件
   chmod +x flash.sh
   ./flash.sh

============================================
常见问题快速解决
============================================

❓ 问题1: 代理连接失败
   解决: 确保 VPN 已连接 (Socloud VPN)
   测试: bash ~/.claude/skills/web-fetch/scripts/test-proxy.sh

❓ 问题2: 下载速度慢或失败
   解决:
   1. 检查 VPN 连接状态
   2. 尝试更换 VPN 节点
   3. 手动下载: https://github.com/espressif/esp-idf/releases/download/v5.5/esp-idf-v5.5.zip
   4. 保存到: F:\esp-idf\esp-idf-v5.5.zip

❓ 问题3: 磁盘空间不足
   解决: 检查 F 盘可用空间 (需要约 5GB)
   或修改脚本中的 INSTALL_DIR 变量到其他盘符

❓ 问题4: 串口未识别
   解决: 安装串口驱动
   CP2102: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
   CH340: http://www.wch.cn/downloads/CH341SER_EXE.html

❓ 问题5: 烧录失败
   解决: 进入下载模式
   1. 按住 BOOT 按钮
   2. 按一下 RESET 按钮
   3. 松开 BOOT 按钮
   4. 重新烧录

❓ 问题6: 编译失败
   解决: 清理并重新编译
   运行 flash.bat 或 flash.sh，选择选项 7

============================================
烧录模式说明
============================================

1. 标准烧录 - 使用默认波特率，稳定可靠
2. 高速烧录 - 使用 921600 波特率，速度更快
3. OTA 烧录 - 通过 WiFi 网络烧录
4. 仅编译 - 只编译不烧录
5. 烧录并监控 - 烧录后自动打开串口监控
6. 仅监控 - 只打开串口监控
7. 清理并烧录 - 清理后重新编译烧录

============================================
串口端口查找方法
============================================

Windows:
1. 连接开发板到电脑
2. 打开设备管理器
3. 展开 "端口(COM 和 LPT)"
4. 找到类似 "USB-SERIAL CH340 (COM3)" 的设备
5. 记下 COM 端口号 (例如: COM3)

Linux/Git Bash:
1. 连接开发板到电脑
2. 运行: ls /dev/ttyUSB* /dev/ttyACM*
3. 找到类似 /dev/ttyUSB0 的设备

============================================
开发板进入下载模式
============================================

如果烧录失败，需要手动进入下载模式：

1. 按住开发板上的 BOOT 按钮 (不松手)
2. 按一下 RESET 按钮
3. 松开 BOOT 按钮
4. 开发板现在处于下载模式
5. 重新运行烧录脚本

============================================
环境配置详情
============================================

代理设置:
- HTTP_PROXY=http://127.0.0.1:7897
- HTTPS_PROXY=http://127.0.0.1:7897

安装路径:
- ESP-IDF: F:\esp-idf\esp-idf-v5.5
- 工具链: C:\Users\<用户名>\.espressif\tools

环境变量:
- IDF_PATH=F:\esp-idf\esp-idf-v5.5
